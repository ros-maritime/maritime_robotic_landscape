    Package catalog¶

    Every open-source project this site tracks, in one place. Type to search names, purposes, and tags, or filter by category, ROS version, and vehicle type. The same data drives the tables on each Software page.

    Activity comes from the date of the latest commit on the branch that matters for ROS 2 (usually the default branch) and refreshes every week: Active within 12 months, Low activity within 3 years, Dormant older, Archived read-only on its host. Low activity does not mean broken: some stable packages need few changes.

    Missing a project?¶

    Add it to data/catalog.yml with a pull request. Each entry needs a name, a repository or website, a category, the ROS versions, the vehicle types, and a one-sentence factual description. See Contributing for the field list. The full data set is also available as catalog.json for your own tools.
